# About Page Copy Design

## Goal

Align the About page with the homepage's quiet, reflective voice while making the blog's purpose more specific.

## Approved copy

Keep the eyebrow `About` and the document title `소개 — namonak.dev`.

Replace the visible heading with:

> 문제를 풀며 세운 기준을  
> 기록합니다.

Replace the introductory paragraph with:

> 개발하며 배운 내용과 선택의 이유, 다시 확인할 지점을 정리하는 개인 기술 블로그입니다.

Use the same sentence as the page's meta description so search previews and the visible introduction communicate the same purpose.

Keep the existing supporting paragraph:

> 짧게 결론만 남기기보다, 왜 그런 선택을 했는지와 다음에 검증할 지점을 함께 기록합니다.

## Scope

Modify only the About page heading, introductory paragraph, and meta description. Preserve the existing markup structure, line break, typography, spacing, colors, layout, and all other pages.

## Verification

Build the static site and verify that `/about/` exposes the approved document title, meta description, heading, and both paragraphs at desktop, tablet, and mobile widths. The implementation remains uncommitted until review.
