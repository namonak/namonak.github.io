## 메모리 누수 정의

메모리 누수는 할당된 메모리가 더는 사용되지 않지만 해제되지 않을 때 발생합니다. 예를 들면 다음과 같은 상황에서 생깁니다.

- 할당된 메모리의 주소를 잃어버린 경우
- `free` 함수가 호출되어야 하는 상황에서 호출하지 않은 경우

## 메모리 누수의 영향

메모리 누수가 누적되면 사용할 수 있는 메모리가 계속 줄어듭니다. 힙 관리자가 확보할 수 있는 공간이 감소하고, 시스템 전체의 메모리 부족으로 이어질 수 있습니다.
