Linux에서 쉘 스크립트를 수행하는 도중 오류가 발생하면 실행을 멈추게 하고 싶을 때가 있습니다. `make`는 오류가 나면 중지되지만, `make`를 호출한 스크립트는 별도로 처리하지 않으면 다음 문장을 계속 수행할 수 있습니다.

## `$?` 특수 변수 사용

쉘에는 `$?`라는 예약된 특수 변수가 있습니다. 이 값은 직전에 실행한 명령의 종료 상태(exit status)를 의미하며, 일반적으로 성공하면 `0`, 실패하면 `0`이 아닌 값입니다.

일반적인 C 프로그램에서는 `main()`의 반환값이 종료 상태로 전달될 수 있지만, 쉘이 직접 확인하는 값은 자식 프로세스의 `main()` 반환값 자체가 아니라 명령의 종료 상태입니다.

이를 스크립트에 넣으면 다음과 같은 코드가 됩니다.

```bash
make 어쩌구 저쩌구
if [ $? -ne 0 ]; then
  echo "Fail(make) ... $?"
  exit 1
fi
```

## Bash의 `-e` 옵션

Bash에서는 `-e` 옵션을 주면 명령이 오류 상태로 끝났을 때 스크립트를 종료할 수 있습니다. 예를 들어 스크립트 첫 줄에 다음처럼 작성합니다.

```bash
#!/bin/bash -e
```

> 참고: `set -e` 또는 Bash의 `-e` 옵션에는 조건문, 파이프라인 등에서 적용 방식이 달라지는 예외가 있습니다. 오류 처리가 중요한 스크립트에서는 필요한 명령의 종료 상태를 `$?` 또는 명시적인 조건문으로 확인하는 편이 더 분명할 수 있습니다.
